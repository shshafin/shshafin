## System Design & Architecture

**Frontend Architecture**
- Next.js with App Router and server components
- Component composition patterns for reusability
- State management with React Query (server state) and Context (client state)
- Form handling with React Hook Form and Zod validation
- Performance optimization: code splitting, lazy loading, image optimization
- Accessibility-first design with Radix UI primitives

**Backend Architecture**
- Express.js with modular service/controller pattern
- MongoDB schema design with proper indexing for query performance
- JWT stateless authentication with bcrypt password hashing
- Error handling middleware with structured logging
- Rate limiting and security headers
- Async job processing with node-cron for background tasks

**Database Design**
- MongoDB schema normalization and denormalization patterns
- Query optimization through proper indexing
- Transaction support for data consistency
- Aggregation pipeline for complex queries

**Production Deployment**
- Vercel for frontend hosting (automatic deployments)
- Docker containerization for backend services
- Environment-based configuration management
- CI/CD pipeline setup and automation
- Monitoring and error tracking in production
